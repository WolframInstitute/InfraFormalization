# Coverage map

This file lists every Lean module of `InfraFormalization` by topic, with the status of its theorems. [`INDEX.md`](INDEX.md) gives a longer entry per module, [`THEOREM_STATUS.md`](THEOREM_STATUS.md) gives the status of each cited theorem, and [`INFRAGEOMETRY.md`](INFRAGEOMETRY.md) and [`ROADMAP.md`](ROADMAP.md) describe the planned work.

Status labels:

- PROVED: axioms at most `propext`, `Classical.choice` and `Quot.sound`.
- PROVED-WITH-NATIVE-DECIDE: the proof depends on an axiom generated by `native_decide`. These results are values computed for specific rules, seeds and depths.
- DEFINITIONS: the module contains no theorem.
- OPEN: stated, not proved.

The number after a status is the number of theorems in the module with that status, from `results/lean_inventory.tsv`.
