# Project index

This file lists the main documents of `InfraFormalization` and its Lean modules, with one entry per document or module. New readers start at [`README.md`](README.md).

Status labels: PROVED (axioms at most `propext`, `Classical.choice` and `Quot.sound`), PROVED-WITH-NATIVE-DECIDE (the proof depends on an axiom generated by `native_decide`), MEASURED (script and sizes), READ (from the paper text, with line numbers in `papers/*.txt`), OPEN (stated, not proved). The per-theorem status table is [`THEOREM_STATUS.md`](THEOREM_STATUS.md), generated by `scripts/theorem_status.sh` from `results/lean_inventory.tsv`.
