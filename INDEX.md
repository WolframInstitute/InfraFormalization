# Project index

This file lists the main documents of `InfraFormalization` and its Lean modules, with one entry per document or module. New readers start at [`README.md`](README.md).

Status labels: PROVED (kernel-checked, sorry-free, axioms at most `propext`, `Classical.choice`, `Quot.sound`), PROVED-WITH-NATIVE-DECIDE (the proof uses `native_decide`), VACUOUS (the statement holds for every target because a definition in it does not depend on the target), MEASURED (script and sizes), READ (from the paper text, with line numbers in `papers/*.txt`), OPEN (stated, not proved). The per-theorem status table is [`THEOREM_STATUS.md`](THEOREM_STATUS.md), generated from `#print axioms`.
