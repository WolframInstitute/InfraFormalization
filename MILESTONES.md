# Milestones: infrageometry research programme

Progress tracker for the programme. Checkboxes: `[x]` done, `[ ]` open, `[~]` partial, `[!]` blocked by an external dependency. Every done item carries a status label as in `STATUS_OF_GORARD_CLAIMS.md`:

- PROVED: Lean, kernel-checked, sorry-free, axioms at most `propext`, `Classical.choice`, `Quot.sound`.
- PROVED-WITH-NATIVE-DECIDE: kernel-checked, depends on an axiom generated by `native_decide` (`*._native.native_decide.ax_*`).
- VACUOUS: the Lean statement holds, but it does not concern the object it is named after.
- Defined: definitions, with at most elementary lemmas about them.
- MEASURED: a number from a script run, with the script and sizes.
- READ: a finding about a paper's text, with line numbers in `papers/*.txt`.
- OPEN: not established; the statement is given.

`THEOREM_STATUS.md` lists the status of each cited theorem from `#print axioms`. The library uses `native_decide` in about 100 files.

Phases follow [`INFRAGEOMETRY.md`](INFRAGEOMETRY.md). Sequencing across phases toward a binary black hole merger from a hypergraph is in [`ROADMAP.md`](ROADMAP.md).
