# Status

This document states the current status of the results in the Lean library `lean/InfraFormalization/`, by area. Related documents: [`INFRAGEOMETRY.md`](INFRAGEOMETRY.md), [`BRIDGE_MACHINERY.md`](BRIDGE_MACHINERY.md), [`MILESTONES.md`](MILESTONES.md), [`COVERAGE_MAP.md`](COVERAGE_MAP.md). The status of every cited theorem, generated from `#print axioms`, is in [`THEOREM_STATUS.md`](THEOREM_STATUS.md). Findings on the papers G1-G4 are in [`STATUS_OF_GORARD_CLAIMS.md`](STATUS_OF_GORARD_CLAIMS.md), [`MAJOR_FLAWS.md`](MAJOR_FLAWS.md) and [`FINDINGS.md`](FINDINGS.md).

Status labels:

- PROVED: a Lean theorem, kernel-checked, sorry-free, with axioms at most `propext`, `Classical.choice`, `Quot.sound`.
- PROVED-WITH-NATIVE-DECIDE: kernel-checked, but depends on an axiom generated by `native_decide` (`*._native.native_decide.ax_*`).
- VACUOUS: a Lean theorem that holds, but whose statement does not concern the object its name or documentation refers to.
- MEASURED: a number from a script run, with the script and sizes.
- READ: a finding from the paper text, with line numbers in `papers/*.txt`.
- OPEN: not established; the statement is given.

General facts:

- `lake build` completed with 3642 jobs on 2026-10-23 (recorded in [`STATUS_OF_GORARD_CLAIMS.md`](STATUS_OF_GORARD_CLAIMS.md)).
- The library contains no `sorry` and declares no axioms.

## 1. Core substrate

Abstract rewriting. `Hypergraph V` wraps a multiset of hyperedges; `Rule P`, `Application`, `RewritingSystem` and `Trajectory` are defined in `Rule.lean`, `Application.lean`, `Multiway.lean` and `Causal.lean`. PROVED: one application, and every chain of applications, of a rule with |LHS| = |RHS| preserves the edge count (`Application.size_result_of_conservative`, `size_preserved_by_applications` in `Conservation.lean`; `trajectory_size_invariant` in `RuleDimensionBounds.lean`).

Executable engine (`MultiwayExec.lean`). States are lists of hyperedges over ℕ (`ExecHG ℕ`).

- `MultiwayExec.singleWayStep` applies a maximal set of edge-disjoint matches, chosen greedily in enumeration order. Edges created in a step are not matched in the same step.
- `MultiwayExec.fireAllStep` (with `fireAllEvolve`) applies every match found in the input state, including matches that share edges. It is not a Wolfram model update when matches overlap.
- `allMatches` enumerates distinct bindings, so a state with two equal hyperedges gives one match for a one-edge left-hand side where the Wolfram model gives two.

Bridge from the engine to abstract rewriting (`MultiwayExecBridge.lean`). `ExecHG.toHypergraph`, `ExecRule.toRule` and `ExecSystem.toRewritingSystem_single` cast engine data to abstract data. PROVED: `exec_lifts_well_formed`. OPEN: a simulation theorem stating that every `singleWayStep` is a chain of `Application`s of the cast rule.

Dossiers (`RuleSignatureSchema.lean`). A `Dossier` records a rule, a seed and a list of states; `isConsistent` checks that each state is `singleWayStep` of the previous one. PROVED: `canonicalDossier_isConsistent` (the engine's own run passes the check) and `consistent_dossier_eq_canonical` (every consistent dossier equals the engine's run).

Subdivision rule `{x,y} → {x,z},{z,y}` (`SubdivisionPath.lean`, `SubdivisionAbstract.lean`):

- PROVED: `singleWayStep_subdivisionSys_consEdge_of_ne`: for all a ≠ b in ℕ, `singleWayStep subdivisionSys [consEdge a b] = [consEdge a (max a b + 1), consEdge (max a b + 1) b]`.
- PROVED-WITH-NATIVE-DECIDE: the same equation for all a, b < 8 and all a, b < 12 (`singleWayStep_subdivisionSys_consEdge_fin8`, `_fin12`).
- The closed form `singleWayEvolve subdivisionSys subdSeed n = pathEdges (subdVerts n)` is PROVED by `decide` for n = 0, 1, 2 and PROVED-WITH-NATIVE-DECIDE for n = 3, 4, 5.
- PROVED: `subdivideAll` equals `pathEdges ∘ subdivideVerts` on path-shaped inputs, and `subdVerts n` is duplicate-free.
- OPEN: the closed form for every n.
- `subdivisionTrajectory n := pathEdges (subdVerts n)` is defined directly, not from engine runs; PROVED: it is a path (`subdivisionTrajectory_isPathOf`) with 2^n edges.

Evolutions with hyperedge identities (`CausalHistory.lean`). A `RuleHistory` is an evolution in which each event consumes live hyperedge identities and creates new ones, and its labels form an `Application` of the rule. PROVED (`CausalHistory.RuleHistory.state_step`): event k is an `Application` of the rule to the state after k events. The causal results are in Section 2.

## 2. Causal graphs

Causal graph on hyperedge identities (`CausalHistory.lean`). The causal graph has an edge from event i to event j when j consumes an identity created by i. PROVED, for every update order:

- `CausalHistory.History.consumer_unique`: an identity is consumed by at most one event.
- `CausalHistory.History.succ_card_le`: the out-degree of an event is at most the number of identities it creates.
- `CausalHistory.RuleHistory.antichain_card_le`: for a rule with |LHS| = |RHS| = k and N initial hyperedges, every antichain A satisfies k·|A| ≤ N.
- `CausalHistory.gorardNamedRule_antichain_card_le`: for the rule of G3 line 6202, 4·|A| ≤ N.
- `CausalHistory.gorardNamedRule_ball_card_le`: for that rule, at most 5^t events lie within directed distance t of an event.

OPEN: linear cone growth, stated as `CausalHistory.GorardNamedRuleConeGrowthLinear`: for every N there is c such that in every valid `RuleHistory` of the rule with N initial hyperedges, every event i and every t satisfy |ball i t| ≤ c·(t+1).

MEASURED: cone-growth exponents of the rule of G3 between 0.77 and 1.26 on 9 seeds (cycles, paths, 3D grids up to 300 edges and 2000 events), depending on the update order. Across four update orders the exponent ranges 0.77-1.10 on the 3x3x3 grid and 0.99-1.26 on the 4x4x4 grid. The SetReplace and Python tables differ because the tools use different update orders: the Python rewriter takes the first match in lexicographic order of state positions, and the SetReplace WL method takes the match whose last edge is earliest (via `Shortest`). Details: [`notes/empirical_refutation.md`](notes/empirical_refutation.md) section 4 and [`STATUS_OF_GORARD_CLAIMS.md`](STATUS_OF_GORARD_CLAIMS.md), Claim 1.

Causal relations on hyperedge values. `Causal.causallyPrecedes` (`Causal.lean`), `isCausalPred` (`CausalLevel.lean`) and `CausalEventTrace.deriveCausalEdges` relate events through hyperedge values. They differ from the causal graph on identities when a state holds two equal hyperedges.

- PROVED: `causallyPrecedes_iff_isCausalPred`. The level function of the causal DAG (`CausalLevel.lean`) is defined by well-founded recursion, and the level increases by at least 1 along each causal edge (`level_add_one_le_of_isCausalPred`).
- `CausalEventTrace.lean` defines `tracedSingleWayStep`/`tracedSingleWayEvolve`, `tracedFireAllStep`/`tracedFireAllEvolve`, and `causalDAGOfEvolution`, `causalDAGOfFireAll`, which list value-based causal pairs as two-vertex hyperedges. PROVED-WITH-NATIVE-DECIDE: `causal_pipeline_subdivision_depth2` (the subdivision rule on one edge for 2 steps gives 3 events and 2 causal pairs, Knill value 6).

Knill values of causal graphs. `knillEulerScaled H` sums 6 − 3·deg(v) + 2·tri(v) over the vertices. PROVED (`KnillEulerCharIdentity.knill_eq_six_euler_char`): `knillEulerScaled H = 6·(V − E + T)` for every `H`, where E counts 1-skeleton edges and T counts triangles.

- `CausalDAGKnill.lean` builds chains, a fork, a join, a diamond, a triple diamond, K_{2,3} and a triangle by hand and computes their Knill values (PROVED-WITH-NATIVE-DECIDE). `singleway_evolution_causal_dag_knill` states Knill = 6 for the hand-built chains of lengths 3, 5, 8, 16; it does not involve engine runs.
- `DiscoveredRules.lean` computes `knillEulerScaled (causalDAGOfEvolution sys seedEdge12 4)` for 11 of the 21 rules of `enumerateRules2_1 2` (values 0, −6, 12, 18, 126; `discoveries_summary`, PROVED-WITH-NATIVE-DECIDE). The causal pairs are value-based. For the reversal rule `{0,1} → {1,0}` on one edge, the edge {2,1} produced by event 0 is consumed by events 1 and 3 (event 2 produces {2,1} again), so the pair list contains (0,1), (1,2), (2,3) and (0,3); the causal graph on identities of this evolution is the path 0 → 1 → 2 → 3. The other values were not recomputed with identities.

Lorentzian side.

- PROVED: discrete Lorentz lattice (`Infra/LorentzLattice.lean`: causal precedence, timelike/null/spacelike trichotomy, forward cones), continuum Minkowski space (`Infra/Minkowski.lean`), and the scaled embedding `lorentzIntEmbed`, which preserves causal and timelike relations in both directions (`Infra/ScaledLorentz.lean`).
- PROVED: `causallyPrecedes_implies_timelike` (`Infra/TrajectoryLorentz.lean`) maps a trajectory into 1+0 dimensions through the level function. `fullEmbed_preserves_causal` (`Infra/TrajectoryLorentzD.lean`) and `causallyPrecedes_gives_continuum` (`Infra/FullBridge.lean`) take the spatial embedding and the hypothesis `LightConeCompatible τ φ` as inputs. No theorem in the library proves the hypothesis for any trajectory.
- PROVED: `causalGraph_causalSet_axioms` (`CausalSetComparison.lean`): a finite causal graph whose precedence is antisymmetric satisfies the causal-set axioms.
- VACUOUS: `LorentzianGHObligation` and `CausalDAGContinuumLimitObligation` take a caller-supplied discrepancy sequence and are satisfied by the zero sequence (`lorentzianGHObligation_zero`, `causalDAGContinuumLimit_zero`). `LorentzianManifoldOriginObligation` holds for every target (`any_lorentzianManifold_has_obligation_witness`).
- OPEN: a Lorentzian Gromov-Hausdorff distance and any convergence of causal graphs to a Lorentzian manifold.

## 3. Discrete calculus and spectra

PROVED (no `native_decide` in the modules or their imports):

- Graph Laplacian on a `Neighbourhood V` (`DiscreteCalculus.lean`, `DiscreteCalculusSymm.lean`, `CycleGraph.lean`): linearity, vanishing on constants, self-adjointness, the Dirichlet form identity ⟪f, −Δf⟫ = ½ Σ (f(w) − f(v))², positive semidefiniteness, Σ Δf = 0, and the Laplacian as a `LinearMap`.
- Second differences (`SecondDifference.lean`, `CTwoTaylor.lean`): exact for quadratics; `scaledSecondDiff_tendsto_iteratedDeriv` gives convergence of the scaled second difference to f'' for every C² function.
- Cycle spectrum (`CycleSpectrum.lean`, `CycleHasEigenvalue.lean`, `CycleEigenLimit.lean`, `CycleMatrixSpectrum.lean`): closed-form eigenvalues of the cycle Laplacian, the eigenvalue statement in `HasEigenvalue` form, and convergence of scaled eigenvalues to the continuum circle eigenvalues.
- Matrix Laplacian and heat kernel (`LaplacianMatrix.lean`, `ExpEigenvector.lean`, `HeatKernelODE.lean`): symmetric Laplacian matrix with zero row sums, heat kernel via `Matrix.exp`, `heatTrace` with `heatTrace_zero`, and agreement of the ODE solution with the matrix heat kernel.
- Evolution equations on finite graphs: heat equation with forward-time existence and uniqueness (`HeatEquation.lean`, `HeatEquationUniqueness.lean`), wave (`WaveEquation.lean`), Klein-Gordon (`KleinGordon.lean`), conservation of Σ(u² + v²) for the discrete Schrödinger equation (`SchrodingerEquation.lean`), scalar-field Lagrangian and Euler-Lagrange equation (`ScalarField.lean`). `heatKernel_cycleHypergraph_multi_mode_tendsto` (`HeatKernelDecay.lean`): heat flow of a finite combination of cycle eigenmodes converges to its constant component.
- Simplicial calculus (`KnillCore.lean`): signed incidence `d` on oriented simplices with `dSquared_eq_zero` and `dStarSquared_eq_zero`; Dirac operator D = d + d* and Hodge operator H = D² with self-adjointness; `hodgeOnG_psd` (H is positive semidefinite); `hodgeOnG_dirichlet_zero_iff_isDiracKernel`; the Euler-Poincaré identity `eulerCharacteristic_eq_alt_sum_kSkeleton`; the Wu identity `wuCharacteristic₂_eq_chi_sq_sub_disjoint`; `formanAngleDefectZ_le_six`.
- `KnillEulerCharIdentity.knill_eq_six_euler_char`: Σ_v (6 − 3·deg v + 2·tri v) = 6·(V − E + T) for every executable hypergraph. Its module imports files that use `native_decide`; the proof does not use them.

PROVED-WITH-NATIVE-DECIDE: worked values on small complexes (`KnillExamples.lean`); Knill values of fixed triangulations, listed in Section 4.

OPEN:

- Small-t asymptotics of `heatTrace` (spectral dimension).
- The sum identity Σ_x (6 − T(x)) = 6·|V| − 3·|triangles| for `formanAngleDefectZ` in `KnillCore.lean`.
- McKean-Singer and the other KN items listed in [`resources/Infrageometry/QuantumCalculus.md`](resources/Infrageometry/QuantumCalculus.md).

## 4. Continuum limits of fixed graph families

These results concern fixed families of graphs (cycles, paths, tori, grids) and their continuum counterparts. They do not involve rule evolutions.

PROVED:

- Gromov-Hausdorff-type bounds. For the lattice distance scaled by 1/n there is an isometric embedding into the continuum space whose image is 1/(2n)-dense: cycle to circle (`cycle_circle_gh_bound`, `Infra/GHBound.lean`), path to interval (`path_interval_gh_bound`, `Infra/ScaledPath.lean`), 2D lattice to 2-torus (`torus_gh_bound`, `Infra/ScaledTorus.lean`), (d+1)-dimensional lattice to (d+1)-torus (`dTorus_gh_bound`, `Infra/ScaledTorusD.lean`). `GHApproximation` (`Infra/GHApprox.lean`) packages such an embedding.
- Ball volume on the cycle: `cycleHypergraph_ballVolume_exact`, |B(v, r)| = 2r + 1 whenever 2r + 1 ≤ n (`HypergraphDistance.lean`; also `dimensionCompatibilityObligation_holds`).
- Wasserstein-1 distance on finite supports (`WassersteinFinite.lean`): a pseudometric (`wasserstein1_triangle` and companions) with the Kantorovich-Rubinstein bound `wasserstein1_lipschitz_bound`. On the cycle (`CycleWasserstein.lean`): `expectationDiff_shiftIter_le`, |E_μ f − E_{shift^k μ} f| ≤ L·k/n for every L-Lipschitz f.
- Lattice Riemann sums (1/n)·Σ_{k<n} f(k/n) converge to ∫₀¹ f for polynomials of degree at most 3 (`A6_for_cube`, `A6Holds.const_mul`, `A6Holds.add`, `A6Holds.sub`, `ContinuumLimitStatement.lean`). OPEN: `A6LatticeRiemannObligation`, the same convergence for every continuous f.
- Uniform ball volumes (`RodkeyClassification.lean`): for every hypergraph, adjacency-transitive implies distance-transitive (`distTransitive_of_adjTransitive`), which implies vertex-uniform ball volume and vertex-uniform local dimension; radius-1 ball volume is uniform iff the graph is regular (`ballVolumeOne_uniform_iff_regular`).

Curvature scalars on fixed families. The values below are PROVED-WITH-NATIVE-DECIDE at the listed sizes. Forman is `execFormanScalar` (sum over ordered adjacent pairs of 4 − deg u − deg w + 3·#triangles); Higuchi is `higuchiTotalDoubled` (Σ_v (2 − deg v)).

## 7. Branchial and quantum

PROVED (no `native_decide` in the modules or their imports):

- `Branchial.lean`, `BranchialCommutator.lean`: the branchial relation of the abstract multiway system and its multi-step form `BranchialMultiRelated`, with symmetry, reflexivity and transitivity lemmas.
- `BranchialFinite.lean`: if every state has finitely many successors, every branchial slice is finite (`branchialSliceFinite_of_successors_finite`).
- `BranchialHilbert.lean`: for any finite type S with a symmetric adjacency, `EuclideanSpace ℂ S` with the adjacency as a self-adjoint linear map (`branchialAdjLM_inner`), Born probabilities summing to 1, the uniform weight, and real expectation values of Hermitian observables.
- `BranchialSchrodinger.lean`: `branchialSchrodinger_unitary_evolution`, the equation i∂ₜψ = Aψ with ψ = u + iv and A the adjacency matrix of a symmetric relation has Σ(u² + v²) constant in time.

These results hold for every finite S and symmetric adjacency; they do not use the structure of a Wolfram model branchial graph.

`BranchialEventTrace.lean` relates events of the same step that consume a common edge, using `tracedFireAllStep`. This relation is same-step consumed-edge contention, not the Wolfram model branchial graph. The modules built on it (`BranchialDepthTrajectory`, `BranchialFromInteraction`, `BranchialRSpectrum`, `BranchialUniversalAdditivity`) state results for the fire-all operator.
